# TankForge 车队几何只读审计

基线只读审计对象为原车库索引的 41 个车型；额外检查新车 `de_hetzer_sdkfz1401`。基线之后的修复见 [修复记录](vehicle-fixes-2026-10-09.md)。本节的原始候选不是修复后整车认证。所有角度单位为度，坐标单位为米；部件编号从 0 开始，指各车型 model.json.parts 的序号。

## 结论与覆盖

- 现有 fitcheck 的 41 辆全部输出 0 floating / 0 clipping，退出码 0；该工具排除 imported 活动部件，所以这个结果不能视为全车队无穿模。
- 14 辆车型包含导入模型，共 463 份材质/挂载分片。全部可解压，缓冲区长度、索引范围、贴图编号、挂载/炮塔/火炮/轮组编号有效；没有因无效挂载被运行时遗漏的分片。14 份模型的记录 bounds 与解码后主体网格边界最大差均为 0。
- 检查了全部 visual 部件及实际需要的默认生成炮塔；BMP 两款变体的 hull/road_wheel 借用可完成，未发现借用来源缺失。导入轮组的包围盒中心与运动轴在 Y/Z 平面均未出现超过 65mm 的偏差。
- 补充导入模型的 25 个方位（包含扫描端点）×平射/按方位允许俯角/最大仰角，另检查火炮与自身炮塔的俯仰变化。发现下表 9 个**可复现动态表面相交候选**；数量是相对于同方位平射基线新增的移动部件三角形数量，不能直接换算成孔洞大小或视觉严重性。
- 这 9 个姿态另用游戏实际 buildTank 场景节点变换复核了 11,035 个采样顶点，分析坐标与运行时坐标最大差 0.00000043m。几何相交证据可信；仍需真实 WebGL 画面确认是否暴露在外表面。

- 8 辆程序式模型的主车体 loft 各有 4–8 个零面积三角（合计 48）：T-34 两型、T-54、M8、PzJg I、FlakPz 38(t)、Hetzer、Hetzer Flak。删除这些零面积面后，每个对应车体仍为 0 边界边 / 0 非流形边，当前证据指向 loft 端部重复/共线顶点，不是主车体破洞。
- M8 的开放炮塔上缘、FlakPz 38(t) 和 Hetzer Flak 的开放战斗室外/内壁使用不封端 loft，属于已声明的开放结构。多片炮盾 mesh 存在几何焊接后的非流形连接，不能据此认定缺面。
- BMPT-34 hull 有面积约1.935m²的两组内部横截面边界（z−.247/−.232），及 y1.584 的1.570m²炮塔环开口。位置和成对截面提示内部壳体/炮塔接口；没有外部可见孔洞证据。
- 其余导入模型也保留开放边和非流形边数据；材料分割、炮口、内壳、嵌套零件及毫米量化都会产生计数。**本轮未确认新的外部可见大洞**，不等于全部模型均封闭或无缺面。

## 新车追加：de_hetzer_sdkfz1401（修复后复扫）

当前 packed 模型共37份材质／挂载分片、109,447三角。新增首上装甲按源边界生成，真实 WASM 射击覆盖 y1.70／1.80／1.85 m；主炮与同轴枪口、炮塔乘员及八个轮组已经校准。弹壳袋、弹盒和固定细节改为炮塔挂载，移除了早期报告中+70°的81个新增相交三角候选。

最终导入配置另复扫25方位 × 平射／−4°／+70°。炮耳、固定内装、机枪安装处仍有源模型原有接合；+70°机枪后部附近保留15个局部新增相交三角（x−.4233..−.3940,y1.9931..2.0180,z.1753.. .1856），−4°还有若干小范围机枪接触候选。−135°主炮与车体细长附件在平射就有相交，单独复测0／1／2／3／4°俯角均存在，不能误报成俯角增加才产生的新孔洞。

这些局部接触不等同于外部可见破洞；源几何与开放式炮塔被保留，没有据相交总数宣称整车完全水密或所有连续姿态无穿模。三视图、+70°实景截图与挂载／索引／枪口回归另保留在图形验收输出中。

## 检测边界与复核资料

- 三角检测沿用 fitcheck 的非共面边穿面算法，边界内缩2%，偏向减少相邻边误报；共面重叠、完全包围而不穿表面、2%边缘区内的细小穿透可能漏检。
- 25方位是离散采样，不能证明连续方位范围安全。使用合法俯角表和武器极限；未扫描中间仰角、开火后坐、车辆悬挂压缩、所有机枪活动、所有折叠比例，也未穷举T-10副炮与主炮的组合方位。
- 拓扑不是水密性/外部可见性判断。非流形边、内部开口、重复面和接合没有一概判错；没有完成41辆真实WebGL画面逐姿态复核。
- 文件均位于本 temp 目录：`fitcheck-all.txt`、`topology.json`、`motion.json`、`assembly.json`、`runtime-verification.json`；新车数据位于 `new-vehicle/`。大JSON没有写入仓库。
- 可重跑的临时只读脚本：`export-procedural.mjs`、`topology.py`、`motion.py`、`assembly.py`、`runtime-verify.mjs`。
