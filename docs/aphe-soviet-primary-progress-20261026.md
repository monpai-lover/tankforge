# 蘇聯 APHE 原始文獻進度與限制

已查到蘇聯國防部原版《Руководство по материальной части и эксплуатации танка ИС-3》的[掃描／文字轉錄](https://ru.djvu.online/file/Et4RnujuyLYDl)。書內刊記1955年，內容依1953年批准技術文件；網頁標成1953不能直接替代書內版本。

紙本94、96頁的彈藥表列出 D-25T 適用的 **BR-471、BR-471B**，並明列兩者的 **MD-8** 引信。這支持 `aphe_122_br471` 所屬實裝彈族及其底引信，不證明遊戲目前2.4 ms、15 mm的數字。該處沒有查到156 g裝藥量，因此沒有把二手百科的156 g標為本原文已核實。

遊戲另有 `aphe_122_br472`。它不能因名稱相近就當作上述BR-471B，也未拿BR-471表格替它認證。BR-365、BR-412B、BR-482B、BR-350A及遊戲35 mm估計彈的原始裝藥／引信數值仍保留原有未核實標記。

這是研究進度，沒有新增或上調裝藥質量，也沒有依二手網站改寫引信或穿甲數字。
