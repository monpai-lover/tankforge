# 追猎者车顶机枪底座漂移修复

原装 Hetzer 的遥控 MG34 支座和枪身被挂在主炮的逻辑转向节点上。主炮由 −5° 转到 +11° 时，支座绕炮根横移约 0.51 m；实际应固定在战斗室顶部。

新增 `visual.mg_anchors` 按副武器 ID 指定支座所属坐标系。Hetzer 的 `roof_mg34` 使用 `hull`，渲染支柱与枪身挂在车体节点，独立机枪方位不再减去主炮方位；瞄具和发射口也按固定车体上的支点计算。未指定时继续使用原 `turret` 行为，其他坦克的车顶机枪仍随炮塔移动。

源生成器、可视化 schema 和审计工具同步支持该字段。保持现有支柱高度、坐标、枪盾、MG34 资产、装甲、弹道和倍率。工坊保留原武器时保留固定支座标记；换成新的炮塔／武器时沿用已有替换规则。Sd.Kfz.140/1 换头及其同轴机枪不受影响。
