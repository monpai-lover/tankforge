# 4.7 cm Pzgr.36(t) 原始文獻差異

已直接查看 [TM9-1985-3 原掃描](https://www.ibiblio.org/hyperwar/USA/ref/TM/pdfs/TM9-1985-3-German.pdf)紙本392–393頁（PDF50–51頁），圖365及其續文明確識別 **4.7 cm Pzgr.Patr.36(t)**，供4.7 cm Pak(t)等使用。

文獻列主裝藥為 **TNT，0.74 ounce**，並記錄底引信。這確認遊戲 `apcbc_47_pak36t` 的 TNT 材料方向，卻不確認當前18 g質量：0.74 oz換算約20.979 g。引信2.4 ms／15 mm的數值亦未由這兩頁證實。

本輪保留18 g，不因單一舊文獻的批次／計量差異直接上調威力；需第二份精確變型資料交叉核對。原掃描另有奧地利Pzgr.35(ö)與鎢芯Pzgr.40，已分開辨識，未把相鄰條目的材料或質量套入36(t)。沒有新增資料覆蓋。
