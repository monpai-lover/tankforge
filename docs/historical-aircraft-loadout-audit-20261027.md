# R8 aircraft loadout audit, 2026-10-27

Scope: `D:/TankForge-workspaces/r8-20261027/worktree/online-source`, R7 plus delivered mount-v4. The baseline has **28 logical types, 17 physical imported models and 106 indexed configurations including guns-only**. Of those, the original 26 types retain 96 configurations: the original 93 plus R7's three F-15E Mavericks. This audit preserves all 106, not only the original 93.

This is an evidence-bounded audit, **not a claim that all historical stores are now complete**. An aircraft-level armament list proves the named carrier, not every possible station, adapter, quantity or service date. Existing source options and fitted geometry establish the game's current attachment permission. They are not represented as new official airworthiness clearances. Current aircraft `year` remains its source identity/introduction/availability label; later equipment evidence is dated separately.

## Findings and approved design

The first safe changes are 12 named configurations for stores that were already selectable in custom armament. The helper adds no compatibility row, socket, rack, flight figure, guidance mode or new weapon definition. It appends to the existing arrays after R7. Its actual exported item positions, owners, mass definitions and ammunition come from the same production `layoutStores`, custom-slot and native profile paths.

The four target identities are checked by **variant name and operator**, including `f15c` = the existing USAF F-15E, `a10a` = A-10C, and `mig21` = **NVA/East German** MiG-21MF. A Polish MF's armament list is not accepted as proof of the NVA MF's radar or missile fit.

The side-specific Sniper entry exposed a real source bug during the regression: `airSlots` ignored an entry's fourth explicit-side field, thereby inventing a left chin station. The staged patch now honors that field when deriving slots. All old source options and all old `slotItems` remain byte-equivalent as JSON.

ROOT approved a separate narrow R4M data-role correction required by the strict pressure validator: the [Smithsonian air-to-air R4M record](https://airandspace.si.edu/collection-objects/rocket-air-air-r4m-orkan-hurricane/nasm_A19990015000) gives **520 g of Hexogen**. Legacy source had 1 kg filler inside a `mass_kg: 0.52` projectile record. The candidate uses 0.52 kg filler and derives the projectile mass from the unchanged store total, 3.85 kg. **3.85 kg remains the existing game estimate**, not a newly measured historical mass. It changes no carried rocket mass, count or preset entry.
