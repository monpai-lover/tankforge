# 27 款程序车辆：几何证据与复查范围

审计从 `afbab48` 的普通车库数据开始，默认对象是 `load-data.mjs` 中没有 `bundle.model` 的 27 款。15 款有导入模型的车辆不会进入默认扫描；显式传入其 ID 也会被拒绝。本记录是修复前的候选证据，最终修复与实景确认由车队交付记录汇总。交点数量不能当作外露孔洞面积或问题严重度。

## 可重跑工具

在 `client/web` 中运行：

```sh
node tools/procedural-fleet-audit.mjs --out=dist/procedural-audit/report.json
node tools/procedural-fleet-audit.mjs de_pz4_h us_m901_itv --out=dist/procedural-audit/targeted.json
node --test test/procedural-fleet-audit.test.mjs
```

工具只读取生产数据，输出候选 JSON，退出成功表示扫描完成，不表示候选均无问题。默认每个炮塔扫描合法方位端点及 24 个等分区间、平射／半俯角／最大合法俯角／四分之一至最大仰角、0／50%／100% 后坐。折板车辆另扫描 0／25%／50%／75%／100% 折叠比例，使用运行时的折叠方位及俯角表；折板自身也与固定车体比较。屋顶机枪扫描合法横向端点与中间方位、平射／最大俯角／半仰角／最大仰角。

每个源部件调用游戏的 `addPart`，枪管使用实际口径开孔，再放入 `buildTank` 的真实炮塔、火炮、后坐、折板和机枪节点变换。源部件缓冲区与实际合并网格的最大顶点误差为 `2.29e-7 m`。机枪使用游戏加载的 `mg_models.json` 和实际生成的护盾、支柱。报告保留源 `visual#N`、挂载、方位／俯仰／后坐／折叠比例及交点坐标，便于实景复现；编号从 0 开始。

既有 `fitcheck.mjs` 的零结果没有覆盖这些候选：它不扫描火炮最大仰角与车体、非 `recoil:true` 火炮部件的炮塔碰撞、实际后坐位移、机枪仰角；其 2% 三角边缘内缩还会遗漏细小交叉。新工具保留基线已有接合，比较交点位置变化，避免仅靠交叉三角数量变化筛选。

程序侧最终扫描完成 27 款、17,054 个姿态，固定连接候选为 0。该次读取的 HVSS 轮组已包含并行修复，因此报告是本轮审计的一个输入快照，不能冒充完整未改动基线。以后每车输出附有 `sourceFingerprint`，用于区分车辆／武器／外观数据输入。

可供针对性回归导入的 API 为 `runtimeParts(id, data)` 和 `surfaceCrossings(A, B)`：前者的 `at({yaw,pitch,recoil,fold,mgYaw,mgPitch})` 使用弧度及 0–1 后坐／折叠比例，返回带 `id` 和世界坐标 `tris` 的源部件。后者返回相交三角数 `count` 和交点 `points`；`auditVehicle(id,data,{yawSteps:24})` 可用于完整单车复扫。确认清除某一外露 pair 后，可在 focused test 中要求它的 `count === 0`；不能用该断言清除全部设计接合。

## 浮空、开放面与限制

固定连接图没有确认新的浮空源部件。早期 CMP 平台误报已撤回：横向平台托梁 y0.74 与纵向车架顶面 y0.74 精确共面支撑，不能靠顶点到面的少量采样判断。工具增加真实边到边距离，并用该源尺寸写入失败后通过的回归。

所有应封闭的主要车体源部件，焊接同坐标顶点并丢弃零面积面后，边界边均为 0。8 个车体 loft 合计 48 个退化三角未造成焊接边界。`de_flakpz38t` 和 `de_hetzer_flak` 的 `#1/#2` 各有 16 条开放边，是明确 `caps:[false,false]` 的开放战斗室壁；`de_hetzer` 的 `#12` 有 56 条开放边，是炮盾套接口，同样明确不封端。未据这些数字声称外部破洞。

该工具检查离散姿态，不能证明连续运动绝无穿模。共面重叠不当作穿透；完全包围、互相抵消的重叠壳、不同活动组的所有独立角度组合、车辆俯仰／侧倾／悬挂压缩及弹性变形均未穷举。固定连接使用 12 mm 容差，记录单位为米。镜像部件仍按源部件记录，不表示逐个镜像小岛均有独立支承证明。乘员几何及运行时自动生成内装由主审计的真实 WebGL 多视角单独核查。

本诊断的 5 个测试覆盖窄边交叉、闭体包含、窄梁共面支撑、法线拆点焊接／缺面以及运行时网格／炮口／后坐／折板映射。真实车型候选仍需游戏画面与来源结构确认后，才能修改生产生成器或活动范围。
