- 创建并推送公开 TankForge 仓库；研究 Claude-of-Tanks 的前后端、画面、着色器与特效，
  汇总 Markdown，遵守参考资源的许可范围。
- 加入 Hetzer_Sdkfz1401_Turret.glb 改装变体，沿用已批准武器方案；精修追猎者，
  保留换头功能；检查未提供 GLB 的整车造型、穿模、浮空、空洞和现实对应。
- UI 缩放同步车库载具；结构展示适度放大；零件显示稳定；更新改装工坊。
- 防空车和拖拉机火炮挡板下放并扩展射界；追猎者挡板可选下放；移除埃塞俄比亚
  拖拉机发动机罩顶上横放的长柄铲子；核对排气口、机关炮制退效果与装配。
- BMP-K64 系列履带齿/轮组联动、火炮俯仰、默认收起舱盖，装甲采用 T64 底盘数据。
- 双发导弹连续射击、弹药 5 切换、轮式车加速和整车起步翘头；T10M/Oplot 单独开火。
- 分化瞄准的准确准星、机枪底座稳定、炮镜无遮挡、遮挡时摄像机前移；第三人称
  仰角支持防空；老/新装备均扩大炮镜，现代瞄具性能应更好。
- 导弹过载和 G 力；激光测距快速测量、合像测距加速；机枪也显示 HIT。
- 导弹/火箭内构采用实际弹药本体和发射装置，移除不适用的炮闩结构。
- 海岸河口 ABC 三点；单人靶场按距离由薄装甲旧车到先进装甲目标排列。
- 短按 F 测距、长按 F 三秒修复读条；轮圈、扳手和外圈进度；长按 J 三秒放弃车辆。
- 采用已批准模块化损伤 A：修正模块命中、武器独立损伤、轻伤性能、修复与乘员兼任，
  保留 F/J、追猎者换头及 X 光回放。
- 休闲/历史模式；休闲提高驾驶、炮塔与射速等性能；历史采用真实数据并隐藏敌人位置
  和名字；Oplot 新改装版保留六管结构，将 14.5 mm 换成 23 mm。
