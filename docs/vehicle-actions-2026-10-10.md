# 长按修复与放弃车辆

用户确认保留短按 F 测距，将修复改为停下后连续按住 F 三秒启动；连续按住 J 三秒放弃车辆，读条时提示松开取消。

## 操作与进度

| 操作 | 结果 |
|---|---|
| 短按 F，不超过 0.35 秒 | 松开时测距，沿用原自动装表 |
| 按住 F，超过 0.35 秒 | 显示轮圈、中心扳手、外圈进度与准备修复倒数 |
| 连续按住 F 满三秒 | 只启动一次原有修复；速度需不超过原门槛 1 m/s |
| 未满三秒松开 F | 取消准备，不测距；再次按下从零开始 |
| 修复已开始 | 进度环转为实际修复剩余时间；松开 F 仍继续，实际时长由原损伤核心决定 |
| 按住 J | 显示放弃车辆倒数、退出图标与警示色 |
| 连续按住 J 满三秒 | 只执行一次放弃车辆，可以在移动中执行 |
| 未满三秒松开 J | 取消；再次按下从零开始 |

轮圈提示位于准星下方和弹药条上方，不拦截鼠标操作。离开战斗、暂停、阵亡、打开聊天或输入框、窗口失焦、页面隐藏会取消未完成的长按。修复准备过程中速度超过门槛也会取消。按键重复与交替操作不会留下延迟触发。

联机修复继续发送既有 repair 请求。联机弃车提交既有 respawn 请求，活着时由服务器处理弃车、死亡与后续重生；客户端不抢先宣布死亡。离线弃车经实际 WASM 战斗核心重算损伤能力，停止驾驶、巡航与开火。

R 保留离线复位与联机阵亡后重生；活着的火箭发射车仍用 R 发射火箭，阵亡后 R 可以复位／重生。原联机双按 R 弃车改为提示按住 J，K 灭火保留。操作帮助、联机提示和 README 同步更新。
