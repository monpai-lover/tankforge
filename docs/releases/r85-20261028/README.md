# R8.5 台海、海水与交互修复（2026-10-28）

基于 `dc106c1a0bf55c74d768d5360b76cc85f2381700`，在隔离工作区实现。本轮范围如下，早期交付记录保留各自的验证边界。

## 本轮变化

- 台海地理距离与源高程改为 **1:10**，原始 `taiwan.json` 不变。小地图仍为原来的 **188×188 框、位置、10 km 半径／20 km 窗口**；改变实际地图内容，未放大 UI。局部机场、跑道和载具仍用米制尺寸，跑道 1600×45 m、附近空中出生 650 m／180 m/s。
- 舰队从 5 艘扩展为 **14 艘、双方各 7 艘**，使用 6 种共享接触／渲染模型，含运输、登陆、护航、护卫、截击和巡逻用途。新增通用登陆舰、护卫舰、巡逻艇均为游戏用自制近似模型，不宣称还原真实舰型或机密性能。舰队保留并行航路和独立泊位。
- 舰船头顶显示阵营、类型、编号和距离；沿用现有 HUD 标签排布，只读取已获准的服务端快照。死亡、屏幕外、后方和超过 10 km 的标签隐藏。数值舰队阵营与玩家 blue/red 阵营映射已验证。
- 地图扩大后运输航程增加，剧本期限同步调为 **2700 秒**，卸载仍为 15 秒；中方护送登陆、台方歼灭进攻舰队的胜负规则保留。实测首次舰队射击约 422.95 秒，运输舰 2011.5 秒开始卸载、2026 秒完成。整个战区采用有界后台地形网格，半径 27600 m／步长 300 m；最终浏览器实际上传地形 **317823 个顶点**、注册水面 **13725 个顶点**，机场局部实体单独保留。
- 海水适配 afl_ext 的 Shadertoy [Very fast procedural ocean](https://www.shadertoy.com/view/MdXyzX) 的 MIT 波形，加入八层解析梯度、导数拖曳、像素尺度过滤和水面光学。保留现有海面几何、高度、碰撞、天空、阳光和色调映射；没有添加全屏步进或额外纹理／渲染目标。源码、完整 MIT 许可和改编说明随仓库、HTML 与两个交付包保留，详见 [来源记录](../../../handoff/tools/r85-water-sources.md)。
- 修复 **MiG-17 挂载按钮点击无反应**：浏览器把 `selected` 属性规范化后，原界面不断认为内容变化，每次服务端刷新都替换按钮，吞掉点击。现按生成内容缓存控件，保留正在操作的选择，真实内容改变时才更新。机场整备和大厅同类控件也使用明确的内容更新边界。
- 自定义挂载数量现经过客户端、协议、原生目录校验和接受值回传。F-15 选择每侧 1 枚时，实际生成总共 2 枚；原机接管不免费重置库存，机场换装在原机上完成原有 15 秒原生整备。旧客户端省略数量的调用继续兼容，数量不能超过服务端目录。
- 退出多人空战调用完整的本地车库恢复流程，清理观战、原生飞控、镜头和输入，再恢复单人地图／驾驶。
- 防护分析保留完整可信模型数据，并使用正确渲染器查询注册三角面。每条独立悬停／试射使用新的私有分析生命状态，避免第一次预览后的乘员／炮管状态污染下一次查询。复用已验证的缓冲和 GPU 模型，不重置实际车辆损伤，不用抽象装甲补上真实模型空洞；临时失败允许下次查询恢复。
- **新目标命中回放在同一次处理立即切换**，不再等旧动画结束。旧目标快照在新快照成功取得后才释放；同一目标连续命中继续叠加弹体、轨迹和爆炸。玩家死亡回放优先级、战局／生命身份验证与真实 V3 渲染器保留。
