# R8.6 海水与飞行舰队标记（2026-10-28）

基于已发布 R8.5（`64e657b`），本轮完成三个明确改动，并提供给 VPS Codex 的完整升级交接。

## 改动

- 飞行底部不再显示遮挡操作栏的护送长条。原生任务与卸载进度改在原小地图内简要显示；观战和下一位队友操作保留。
- 舰队位置标记现在画在可见的飞机 HUD。原错误是它画在飞行 CSS 隐藏的陆战画布：观战可见、驾驶不可见。座舱和第三人称共用修复后的路径。
- 战略舰船标记读取服务端允许的存活快照，最多检查 64 条，范围 80 km，屏幕内最多 16 条；屏幕外或后方最多每方一个方向提示，双方同方向时分开排布。标记点不随文字避让移动；边缘标签向内排并限制在视口内。小地图仍是原 188×188、附近 10 km；台海 1:10 与双方各七艘舰队保留。
- 海水按用户提供的 Frank Hugenroth（03/2013）参考适配：五组交错长浪、四层 fBm、七层细浪及天空／太陽反射。缺少的原噪声图片明确改用游戏噪声；解析梯度与像素过滤控制开销。保留实际海面高度、碰撞、现有镜头和非水材质，未导入独立演示的整屏步进或体积云。
- 此次海水适配为 **CC BY-NC-SA 3.0**，不是 MIT。作者、原附件、改编说明和许可链接随代码、HTML 与完整包保留；旧 MIT 来源和通知也保留。
- 旧版幂等组合器现在能保留 R8.6；修复了跨平台 CRLF 输入的组合兼容性。R8.5 打包脚本固定原版指纹，当前完整打包入口为 `tools/package_r86_full.py`。
