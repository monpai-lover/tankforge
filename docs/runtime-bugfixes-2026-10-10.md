# 起步、独立武器、发射车内构与海岸河口修复

日期：2026-10-10。本轮对应用户报告的六项问题。

## AT-T／M-46 横放铲子

前轮移除了格栅前的竖架和链条，却漏掉用户所指的发动机罩顶横放长柄铲子。本轮从原 GLB 的 `Exterior_Details` 连通组识别木柄、钢刃和两个固定扣，分别删除 64、204、32、32 个三角面，共 **332** 个。结合前轮 2,636 个面，累计移除 2,968 个，当前可玩模型为 **159,493** 个三角面。

剩余部件的顶点、法线、UV、索引、节点属性和贴图逐项保持一致；原始来源 GLB 归档保留原字节，六组 I 键折板继续使用原来的铰链。连续两次定向重建保持当前车型数据与来源文件字节一致。

## 轮式车加速

轮式车此前沿用履带的 1.5 秒接合时间；轮胎先计算上一时步的滑移，再加入驱动冲量，还会制造虚假空转并提前触发断油。现改为轮式车 0.35 秒接合，在驱动／制动后同时求解轮胎与车体的滑移响应；履带仍使用原接合参数。

120 Hz 平路测量，单位为秒：

| 车型 | 0–10 km/h 修前 → 修后 | 0–20 km/h 修前 → 修后 |
|---|---|---|
| M8 | 1.43 → 1.17 | 3.76 → 3.48 |
| Puma | 1.34 → 0.93 | 3.65 → 3.19 |
| BMP-K64 | 1.60 → 1.23 | 3.70 → 3.25 |
| W78 | 1.28 → 0.80 | 2.75 → 2.18 |
| KDA35 | 1.25 → 0.79 | 2.70 → 2.14 |
| CMP | 2.15 → 1.73 | 4.98 → 4.53 |

独立检查覆盖全部八个轮式条目，平地起步峰值俯仰为 0.94–2.76°；使用 1/240、1/60、1/30 秒时步，十秒后速度的最大差异为 0.41%。不靠提高发动机功率恢复加速。

## 机枪瞄具与 Oplot-MO

G 选中机枪后，装表、测距和分划使用该机枪的数据与实际炮口，并处理机枪与镜头的视差；坡地时按车体的真实姿态换算。选中同轴机枪时使用机枪的弹道表驱动瞄准。

T-10M 选中 Oplot-MO 后暂停自动拦截，允许左键独立开火；切回其他武器时恢复 U 键设置的自动防护偏好。手动射击和自动拦截共享同一弹药池，服务端仅对接受的射击扣弹，重复、无效、空弹药和损坏的防护枪均不额外扣弹。

## 导弹与火箭内构

M901、BMP-K64 两个导弹变体以及 BMPT 火箭架按武器类型构建发射装置与逐管弹药本体，射出后隐藏对应弹体，重新装填后恢复。发射武器不再生成常规火炮的炮闩与后座结构；BMPT 的两门 25 mm 火炮仍保留自己的炮闩。

模块资料新增 `launcher` 类型，并贯通内视标签、损伤、服务端、WASM、来源生成、模型导入和工坊导出。受损发射架只限制相关发射装置；混合武器车型的常规火炮与另一侧完好火箭架继续可用。

`weapon_group` 按安装实例组织同一套装置的关键部件；一套内任一关键部件损坏则禁用该套，另一套完整装置仍可用。缺少此字段的旧发射模块按原来同一套装置处理。

现有联机发射消息不携带安装位身份，因此服务端检查车辆是否仍有完整可用的发射装置，客户端检查实际选中的安装位。本轮未扩展网络协议为逐安装位鉴别。

## 海岸河口 A／B／C

用户确认“丛林地图”为海岸河口。新增三个半径 45 m 的占领点：

| 点 | X / Z（m） | 位置 |
|---|---|---|
| A | -260 / 100 | 西岸林缘 |
| B | -90 / -360 | 中部桥头岛 |
| C | 250 / -100 | 东岸林缘 |

原地形、贴图分类和出生点保持不变。三个占领圈均在水面以上，远离出生点；独立 2 m 地面连通检查确认双方出生点与三个点之间可通行。客户端占领、争夺与票数消耗使用这些点，服务端加载同一资料。

`data/maps/coast/points.json` 是占领点的来源文件，`tools/map-prep.py` 重建地图时读入；临时目录实际重建测试确认不会丢失 ABC。
