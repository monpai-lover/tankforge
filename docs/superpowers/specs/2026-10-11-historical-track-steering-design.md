# 真實履帶轉向修正設計

2026-10-11。Status: proposed; awaiting user review before implementation.
Project: TankForge. Baseline4057976; branch `codex/historical-track-steering`.
完整來源、35款履帶車分類及實際錯誤重現見
[研究文件](../../vehicle-steering-research-2026-10-11.md)。

## 使用者目標

不支援雙履帶反轉的真實車型不得用兩側反向旋轉完成中心原地轉向。
支援單側制動緊轉的車，一側停止、另一側行駛，車體中心走弧線。
M4/M10真實控制差速器是例外：轉向制動不能完全停止对应履帶。
Tiger、Panther、Cromwell及現代Gepard的有據中性轉向保留。

## 接受範圍

1. 新增JS/Rust共同讀取的獨立可信車型能力表，涵蓋35個履帶ID並區分來源可信度。
   21個制動緊轉ID、5個中性轉向ID、5個控制差速ID、3個保留未確認ID、1個原創ID。
   對8個輪式ID明確不套用履帶轉向。最小半徑不再等同中性轉向開關。
2. 修正JS完整履帶驅動與接地求解，Rust鏡像同步；快速平面物理／設計局的能力
   評估也依同一機構規則，不另造能力表或偷偷保留假中性轉向。
3. 單側制動從原發動機、傳動及接地力預算產生；解除停止側主動驅動並施加有限
   制動力。行星／控制差速約束應被動交換／消耗動能，無外部能量注入；各側引擎
   作用的總功率受原發動機及既有損傷門檻限制。可反轉車保留其獨立動力轉向。
4. 從停車的A/D自動以低檔小油門轉彎是建議操作；W/S+A/D保留，倒車停止側
   與轉向符號一致。選擇若改為必須W/S，僅改此輸入映射，不改歷史能力分類。
5. 工坊從底盤繼承可信轉向能力；換頭、保留原武器、自訂武器、导出及再導入不能
   把制動車恢復成可反轉車。導出轉向欄位要在Rust與JSON schema中嚴格驗證。
6. 休閒與歷史均遵守同一機構能力。休閒既有牽引／速度／轉向倍率保留且只套一次，
   不提供額外中性轉向；原始資料、工坊匯出數值與性能派生分離。
7. 車庫顯示玩家可理解的機構類型，標明未知／原創設定；不展示求解器細節。

## 檔位與來源邊界

緊轉使用有據檔位：T-34一檔；IS-2低速範圍四檔／加速第一檔及倒檔；T-10M
一／二檔。T-10M的硬地三檔例外不在初版採用，普通停止制動限一至四檔。
在不允許緊轉的較高檔位，使用普通同向轉彎及原自動換檔／減速流程，不能直接
清空車體或履帶速度、瞬間跳檔。T-54／AT-T未核實額外檔位限制，不捏造數字。
手冊減速階1.35／1.42可作已知PMP普通轉向的可信參數；未確認的齒輪比例保留
既有估計，不能把遊戲控制插值說成完整逐齒輪／手動操縱杆模擬。

M56、VK1602及Aufklärungspanzer Panther資料不足；保留原配置並明示未確認，
不憑外形或cross-drive名稱臆造能力。Gepard、PantherF、炮塔改裝型屬已列明的
共同底盤／傳動推定，不宣稱曾逐改裝型歷史實測。

## 實作限制

- 原始vehicle/engine/armor/weapons、GLB與packed模型保持原字節。修正用獨立能力
  層及衍生參數；不能重產原車隊。main既有三份BMPT参考文字換行保留。
- 主工作區4057976隔離研究於既有工作樹，主main不直接寫未驗收源碼。
- 一個運行時writer；每個實作檢查點fresh SPEC→fresh QUALITY，修復交原writer。
- 不複製或修改舊B2未完成工作樹，不放寬原測試容差；13+2凍結保護維持。
- F短按／長按、J、獨立武器、追獵者換頭、輪組慣性、命中與回放保持回歸。
- 聯網不能從玩家／entity ID推斷車型；遠端履帶速度／連續行程按實際狀態重建。
  既有服務端粗粒度移動檢查不因此變成完整轉向反作弊，禁止如此宣稱。
- 停止側可在強外力／滑地上滑移；禁止硬設belt.v=0或hull yaw。接地、制動與
  有限功率是行為來源。不得增加已建立熱迴圈的額外每步集合配置。

## 驗收

- 先以實際loadData／makeParams／driveStep／solveFriction重現既有假反轉RED；
  完整平地模擬驗證停止側平均履帶行程接近0、外側累積行程及車體弧線位移，
  相比中性車呈現不同路徑。容差取求解器既有精度與力上限，不能消除真實滑移。
- 前進、倒車、左右、steer-only、部分轉向、鬆鍵、制動、高低檔、坡面／低摩擦、
  空中履帶及外力，验证有限制動、無假主動反轉或強行車體鎖定。
- 无引擎／drive_power0、換檔、傳動損傷、單／雙斷帶沿用原門檻；被動制動不
  得注入能量。傳動約束與引擎正功率／衝量預算需獨立數值測試。
- 列表全ID、變體／工坊／source export及mode倍率，快速平面／完整JS／Rust parity，
  網絡左右速度與履帶行程。數據驗證／typed optional字段／schema均需實測。
- 新功能及相關全量Node／native回歸；必要時重產有意改變的同步觀測資料，
  明確记录RED及改變內容，保持原有物理驗收門檻。
- 真正release WASM與命名新頁、target／asset／單一designCore匹配，保留已交付
  舊模式／Oplot頁，最後雙審後整合／更新預設頁及既有授權推送。
- 瀏覽器實景驗收此前自動審批拒絕，理由未保留；不以HTTP/CDP/Playwright繞過，
  CPU及建置結果不能冒充畫面驗收。

此設計不實作完整逐齒輪模型、熱衰退／磨耗或B2/P2–P5/V3待辦，不宣稱補完
資料不足車型或所有歷史精確性能。它修正本次可辨識的轉向能力與真實力路徑。
