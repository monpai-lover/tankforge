# 炮塔座圈承载接触复查与修复

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax for tracking.

**Goal:** 按用户已授权的逐车修形范围，确认炮塔座圈／支承是否浮空，修复可复现的几何或挂接错误，保留炮塔、工坊换头和现有战斗功能。

**Architecture:** 以实际运行时三角形及节点变换测量支承接触；粗包围盒仅筛选，不能证明承载。原厂炮塔、父炮塔上的附加炮塔、工坊新装炮塔分开验证。修复源生成器或新装炮塔接合路径，保留旋转轴与武器、装甲、内构标定。导入原始 GLB／packed 网格不盲改。

**Tech Stack:** 现有 JavaScript WebGL2 场景图、CPU 几何工具、Node 回归、Python 定向生成器。基线 `2ebb940`，复用隔离工作树的 `codex/turret-ring-contact` 分支。
