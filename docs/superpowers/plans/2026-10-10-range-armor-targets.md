# 靶场装甲目标实施计划

目标：单人靶场增加 8 辆静止实车目标，距离为 100、200、400、600、800、1200、1600、2000 米；正面车体防护逐级提高，远处采用战后及 T-64 底盘车型。

设计：沿用已有 Enemy、车辆模型、悬挂和 Rust Combat 判定，不改车型装甲。选择 M8、三号 J、四号 H、虎式、豹 G、T-54、T-10M、BMP-K-64；装甲进阶以车体正面厚度及倾角共同衡量，侧面、底部和炮塔弱点仍按真实数据。角度错开纸靶与其他靶车；不放在越野坡顶或悬挂试验障碍上。

执行顺序：

- [x] 新增 `client/web/test/range-vehicles.test.mjs`：实际启动／生成路径、距离及正面防护进阶、地面悬挂、射线遮挡、实车命中及独立状态、离场释放；先运行并记录失败。
- [x] 新增 `client/web/src/game/rangeVehicles.js` 固定车辆及极坐标布置；修改 `main.js`，离线靶场使用这些目标，其他地图沿用原敌车。
- [x] 靶车采用独立 Combat 注册键，保持静止，不启用主动防御及攻击 AI。复用车辆标签显示靶距、车型和当前距离；远处靶车标签保留到 2000 米。核心延迟就绪时也绑定已有目标，测试先重现再通过。
- [x] 定向测试通过后跑完整网页回归、实际 WASM／网页构建；不访问此前被浏览器策略拒绝的本地游戏页面。
- [x] 独立代码审查、更新说明文档与 README。

发布流程：精确提交、快进合并并推送；同步所有本地 standalone 游戏页面，核对文件哈希。

验证只运行 Node 的实际模型、物理、Combat 和 HUD 代码，以及构建产物核对。本轮不声明浏览器实景验收。沿用现有干净工作树和依赖，不清理此前被策略拒绝清理的工作树。
