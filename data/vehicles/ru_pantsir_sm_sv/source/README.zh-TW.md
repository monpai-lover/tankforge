# Pantsir SM-SV 保形清晰版 V2

直接開啟根目錄的 **Pantsir_Preview.html**。預設顯示保形精細版，已恢復原始圓管、輪組、車體接縫、小配件、UV、分裂法線與法線貼圖。可離線旋轉模型、檢視裝甲與內構、拆甲、瞄準及發射武器。

體積採十進位 MB。精細版含外觀 291,829 面及新增內構 4,372 面，主要保留原始幾何，檔案體積比來源減少 24.28%。平衡版外觀 167,250 面、內構 2,242 面，外觀面數比來源減少約 42.7%，檔案體積減少約 51.1%。遠距版外觀 110,869 面、內構 1,380 面。三個版本都使用新的保形流程，舊三萬面變形版已停用。精細版適合近距離檢視，平衡版與遠距版依效能需求選擇。

原始 GLB 保留在原位置。SHA-256：`044a1d62df9bb11ab1a6854371fad54989079eebf4226e149bdeb5d9a854732a`。

## 開啟與操作

1. 開啟 **Pantsir_Preview.html**。桌面瀏覽器需支援 WebGL2。
2. 拖曳旋轉、滾輪縮放；按「前」「側」切換視角。
3. 「外觀／裝甲／透視」切換顯示方式；「結構展開」可拆開觀察。
4. 點選表面查看零件與遊戲用裝甲資料；選擇裝甲後，可移除該片裝甲。按「還原零件與武器」恢復。
5. 透視模式中勾選「選取內部模組」，可檢查引擎、傳動、油箱、彈藥、乘員、座椅、電子設備與結構件。
6. 用炮塔方位及武器俯仰控制瞄準；可逐枚發射 12 枚導彈、重新裝填，以及點放雙側雙管機炮。
7. 精細版帶有 `radar_scan`、`aim_demo`、`cannon_fire`、`missile_launch_demo` 四個動畫片段。較低 LOD 保留可動節點，使用直接控制，未重複烘焙動畫。

若要開啟分檔檢視器，可執行 **Start_Preview.cmd**（需要 Python 3），或使用 **Start_Preview.ps1**。它會在本機啟動檢視頁。分檔版本與單檔預覽使用相同模型及程式。

## 交付內容

- `assets/pantsir_master.blend`：可編輯原檔，含三個 LOD、機械關節、材質、動畫和獨立內構。
- `assets/pantsir_lod0.glb`：保形精細版本，保留原始迷彩、UV、分裂法線、法線貼圖、命名節點及 16 個武器定位點。
- `assets/pantsir_lod1.glb`、`pantsir_lod2.glb`：較低細節版本。
- `assets/scene_manifest.json`：部件、父子關係、座標、定位點與輸出統計。
- `data/`：裝甲、內部模組、乘員、武器、動畫與特效資料，以及含內容雜湊的三角形 hitbox 資料。
- `integration/`：TankForge 的 `model.json` 視覺匯入檔、設定、獨立關節／發射／特效與命中查詢接入檔，詳見其中的 README。
- `evidence/`：實際瀏覽器測試、模型重新匯入、幾何核對與預覽截圖。
- `tools/`：重建、驗證及打包工具；不影響一般預覽操作。

模型重建使用 `tools/build_asset_v2.py`，先輸出至 `assets_v2`，通過保形檢查後再發布。舊 `build_asset.py` 已停用，避免重新產生被取代的過度減面版本。

11 個裝甲區與外部配件分開；新增內構共 142 個網格部件，按模組分組。武器配置沿用可見模型的 12 個導彈筒及 4 個機炮炮口。活動內構、炮口與發射點會跟隨關節。

## 裝甲與命中資料的含義

原模型只有外觀，沒有可信的裝甲厚度、內部圖面或武器性能表。新增內構、乘員位置、厚度、抗性、生命值與武器數值均明確標為**遊戲用估算**。這些資料可編輯，不代表實車完整測繪。

表面命中使用實際模型三角形及當前姿態，保留孔洞與縫隙。透視只影響顯示；實際拆下部件才會停用其碰撞。光學、橡膠／行走部件、配件與武器表面不會因鄰近裝甲而繼承裝甲厚度。混合材質的裝甲節點另有逐材質分區覆寫。

內部模組的健康值與簡化命中體積是近似遊戲資料。它們不會替代裝甲表面命中，也不構成已完成的穿甲／引信／碎片模擬。

## TankForge 接入範圍

本次交付是資產包及獨立預覽。`integration/data/vehicles/ru_pantsir_sm_sv/` 的外觀模型已使用實際 TankForge 匯入流程轉換，保留 291,829 個外觀三角面，並核對 46 組實際上傳幾何資料及大型批次的 uint32 索引。原尺寸貼圖與法線貼圖也會進入遊戲匯入資料。內構保留於 GLB 及部件資料，未混入外觀批次。

TankForge 現有匯入格式會捨棄 GLB 動畫，並限制獨立雷達／發射架關節；交付的 adapter 提供具體接點。正式戰鬥、車庫名單、Rust／WASM／聯機權威傷害未在此包啟用。`integration/combat-candidate/` 是獨立的平衡資料候選，需完成可信表面裝甲註冊後才能接入正式戰鬥；請依 `integration/README.md` 操作。

## 驗證

已對三個 GLB 執行重新匯入、有效索引、有限座標、尺寸、輪組與定位點檢查。精細版另外以雙向各 180,000 個表面點對照原始模型，通過 p95 ≤ 1 mm、p99 ≤ 3 mm、最大採樣距離 ≤ 10 mm 的保形檢查；這是模型座標比較，不是實車測繪精度。瀏覽器測試涵蓋裝甲拆除、透視碰撞一致、炮口孔洞、瞄準動畫、12 枚導彈耗盡／裝填、各 LOD 和窄螢幕版面。另以瀏覽器離線模式直接載入單檔 HTML，核對沒有網路請求。

開啟 **Model_Comparison.html** 可離線比較原模型、修正版、平衡版與已停用的舊版。完整數值與同角度圖片位於 `evidence/fidelity_audit_v2*`。
