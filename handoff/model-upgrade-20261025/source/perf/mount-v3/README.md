# 挂载与目录升级

本目录覆盖现有 18 个喷气条目（含 NF-02 试验机），按实际渲染三角形检查全部预设、全部可选型号站位，以及新增的 10 套混装组合。`jets-audit/geometry-findings.json` 是逐架检查结果；检查包含外挂与机体、外挂之间的穿插和挂点连接距离。

Su-27 增加与原翼端相接的导轨并修正外侧导弹连接。F-15E 保留模型自带的双联挂架，机腹导弹改接原 CFT 挂钩，避免与原瞄准设备相交。其余适配件按当前方案启用；未使用的备用挂架不会留在画面或碰撞中。

副油箱、SPPU-22 双管机炮吊舱、各型火箭巢、电子战/瞄准吊舱改用分类外形；GBU-10/12 补充导引头、前控制面与尾部。新增 Sniper、LITENING 为游戏拟合模型，尺寸、质量与传感器参数按游戏展示/平衡估算。

兼容目录独立于预设。F-15E 补全已有 AIM-120 系列、AIM-9X、GBU-10/12、CBU-87 的站位选项；F-16V 补充 AGM-88B、Sniper 与同系列导弹的遗漏选项；A-10C 补充 Sniper/LITENING、GBU-10/12。单挂/双挂数量可选，旧存档中单枚 AMRAAM 的数量保留；原 F-15 双联轨始终最多两枚/侧。瞄准吊舱可实际提供现有激光指示功能，脱离挂载后取消。

机型/武器对应的主要公开依据见 `catalog.mjs` 的 `SOURCES`。F-15E 与 A-10C 按当前实际模型身份修复，内部旧 ID `f15c` / `a10a` 保留。原有 67 个预设的索引、武器 ID、顺序和数量保留，原武器参数不变。

本地空战集成请同时使用：

- `catalog-capabilities.json`：完整站位选项和新增混装示例；新后端需要开放对应能力。
- `../hardpoints/native-layout-map.json` 与适配器：按模型来源、完整初始外挂序列和旧位置核对后，生成修正的位置/归属。
- `mount-collision-map.json`：与画面一致的物理挂架三角形；原伤害 ID 不增加。按 `fittedMountKey` 为每架飞机独立启用，发射后保留挂架，载体脱落后移除。Su-27 固定翼端导轨列在 permanent 中。

这些文件供生成初始单位和挂载使用。已接受的 Native Frontline 状态仍由原服务器投射；此包未修改用户正在开发的本地后端。

验证：`node --test perf/mount-v3/details.test.mjs`；浏览器几何检查脚本为 `audit-jets.mjs` 和 `analyze-jets.py`。先按根目录 TESTING.txt 从自己的原网页和升级网页提取模型数据。
