当前组合版本另含 `../mount-v3` 的喷气机全目录检查、适配件与新增挂载。下面说明本目录原有 V2 挂点模块；完整当前范围与本地后端接入数据以 mount-v3/README.md 为准。

# 模型挂架与挂载修复

本模块用于当前网页客户端的外观、挂架、外挂安装与部件归属修复。覆盖26个机型、67个已有预设；其中8个导入机型共146处外挂位置发生修正。武器编号、顺序、数量、弹药、质量、阻力和现有能力不变。

- **F-15E、F-4E**：翼下空空武器使用源模型的双导轨；自定义配置不能在同一双导轨挂架上额外叠出第三枚导弹。已有内侧炸弹／火箭巢使用中央翼下挂架的下端，通过短的程序生成载架安装，清除与侧面导弹的穿插。
- **MiG-21**：已有两件外挂移到模型内侧翼下导轨；保留原有配置数量，不因模型另有导轨就增加武器。
- **F-104G、F-16V**：核实过的翼下与翼尖外挂对齐实际源组件；F-16 未独立识别的中／外翼挂点位置保留。
- **Su-27**：已有配置对应发动机舱下、内外翼和前后中线挂架；发动机舱下外挂归属 `body`，断翼不再误抛。翼尖位置保持原值。
- **A-10、Su-25**：取消发射架随武器长度产生的多余前移，发射架的 `socket_aircraft` 与既有连接杆末端吻合；武器 `socket_mount` 精确接到对应 `socket_store_n`。同一个三联发射架只建立一套连接杆。
- **F-4E、F-15E 机腹纵列导弹**：修复原有约1.24米重叠。新位置保留原横向通道，以导弹长度加间隙安排纵距；短连接架从实际机体三角面接出。这是明确标记的程序安装推断，不是已注册的原作者挂点。

MiG-21、F-16 原模型的左右翼分组与空间侧相反，外挂现在按实际源翼组绑定；实际左／右翼脱落投影测试通过。没有改动源三角形、模型蒙皮、飞行内核或损伤部件目录。

## 几何依据

`geometry-audit-mount-table.json` 记录源组件、精确模型哈希、比例、拓扑守卫和测量坐标。导轨／挂架位置取源组件下表面的安装中心；这是几何安装推断，不能冒称原作者注册 socket 或历史挂载认证。所有改动只在匹配的源模型上生效。

`measured-mounts.mjs` 是运行所需的紧凑测量表。`helper.mjs` 和 `patch.py` 都需要它。

## Native Frontline 与本地空战后端

现有 Native Frontline 仍权威决定 `p`、`owner`、`count` 和武器编号。包装器在挂载时投影已接受的合法宿主归属，保留原始接受函数的验证；原有四个带标签的 Native 功能块逐字节保留。客户端不会把修正坐标伪装成服务器坐标。**旧服务器的外挂位置会继续使用旧坐标，直到后端布局接入下述映射。**

`native-layout-map.json` 提供8个机型、30个现有预设的完整原／新位置及归属，对应221个初始外挂对象。`native-layout-adapter.mjs` 是可供本地空战开发使用的纯函数：在初始生成／挂载方案构造阶段，按模型哈希、完整武器顺序、数量、原归属和原坐标匹配，再返回修正布局。保留其他玩法状态，不修改输入，不操作已经发布的实时状态；未知或歧义布局拒绝套用。

```js
const result = applySpawnLayout({
  aircraft, sourceMain: model.sourceHashes.main,
  items: initialStores, phase: 'spawn_layout'
}, layoutMap);
if (result.applied) initialStores = result.items;
```

这些文件是具体后端接入材料；本包没有取得或改动用户正在开发的本地空战后端。新自定义挂载应结合 `helper.mjs` 的测量表及后端自己的武器 socket 模式接入，不能仅按客户端预设序号套表。

## 验证

`test.mjs` 调用实际网页布局函数，验证26机型／67预设的身份、数量、质量和阻力；涵盖实际源翼组脱落、机腹不重叠、完整发射架 socket 链、源模型守卫、自定义导轨容量和宿主归属投影。

`native-layout-adapter.test.mjs` 验证30个初始方案的纯函数接入、幂等和错误输入拒绝。`geometry-audit-mixed-store-intersections.json` 的12组关键混合挂载实际三角面检查均无相交；全67预设包络复查无重叠疑点。包络检查不是对所有复杂网格接触的数学证明。代表机型的真实 Renderer 检查无运行错误、释放点与挂载世界坐标一致。

```sh
python perf/hardpoints/patch.py INPUT.html OUTPUT.html
node perf/hardpoints/test.mjs
node perf/hardpoints/native-layout-adapter.test.mjs
```
