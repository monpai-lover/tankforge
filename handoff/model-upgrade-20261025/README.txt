TankForge 外观、内构与挂架升级包
==============================

本包由已下载的 26 机型网页版本制作，不替换飞行内核或空战模式。
飞机模型、贴图、音效等原始资源沿用输入网页。

安装（Python 3.8 或更新版本）
---------------------------
先解压整个文件夹，在该目录运行：

    python3 install.py "原网页.html" --check
    python3 install.py "原网页.html"

支持原始网页和上一版模型升级网页。Windows 可以使用 py 代替 python3。生成 原网页-models-upgraded.html，
原文件保留；已存在的输出也不会覆盖。

安装器仅替换精确匹配的模型接口，不要求整份网页的哈希与底版完全相同。
你在上下文之外开发的空战脚本保持原样。如果改到了同一模型接口，安装器
会报出冲突段并停止，不做模糊覆盖；可以使用 source 中的模块在本地合并。
请用浏览器打开生成的新网页。此包不会上传或部署站点。

内容
----
- 26 个机型共用正确的飞机机构标签，机库 O 标签不再取用停放坦克。
- O 保留真实机体、机翼、尾翼的半透明轮廓，去除错误的程序框架与代理方块。
- 9 个已有专属内构的条目保留；17 个回退内构深化发动机、油箱、供油、
  液压、电气、武器与弹药机构。油箱仅改变展示剖口，原接触几何保留。
- 细化按需生成；显示附件不新增伤害 ID，也不进入额外的物理碰撞。
- MiG17 襟翼/副翼绑定及固定结构修复，保留原始三角形。
- MiG17、F4、F15、Su27、A10、Su25 的已有发动机/设备舱位修正。
- Me262 三个变体的瞄具移至仪表盘风挡一侧，以短支架安装。
- 损伤小图使用当前机型的实际轮廓与机构。
- 挂载检查覆盖 26 机型的原有 67 个方案；喷气机逐架装载检查，包含全部可选型号与新增混装。
  包含挂架、导轨、发射器及武器 socket 对齐和重复占位修复。详细机型、
  实测挂点和程序推定的站位调整见 source/perf/hardpoints 的审计表。

新增挂载目录
------------
F-15E、F-16V、A-10C 的已建模/已支持但未开放的选项接入独立目录。
补充 Sniper / LITENING 瞄准吊舱及 GBU-10/12 外形，接通现有激光指示。
双联架可选择单枚/双枚数量；保留原方案索引和旧单枚选择。
F-15 保留源模型双联架；Su-27 翼尖导轨与外侧挂点按实际模型重建。
通用适配件只随当前选用的挂点启用，画面和碰撞使用相同三角形。
详细范围、依据、碰撞启用规则见 source/perf/mount-v3/README.md。

联机与本地空战对接
----------------
Native Frontline 的武器位置和归属仍由服务器下发。本包的客户端布局修复
不会覆盖 host.p 或服务器接受的 owner。后端同步请使用挂点模块旁的清单，
按本地后端现有武器 ID/方案接入；客户端预设索引不是后端方案认证。
具体服务端对接范围以 hardpoints/README.md 和最新报告为准。

source 是可合并的模块源码与补丁脚本；verification 是实际检查记录。
服务机构的新增细节是按游戏模型舱位拟合的展示模型，不是生产制造图纸。
